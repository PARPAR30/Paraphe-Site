PARAPHE — SITE DE PRÉSENTATION
==============================
(devise : Du cours au cabinet.)

Contenu du dossier
- index.html ............ la page (HTML + CSS + JS dans un seul fichier)
- diligences.html ....... la visite guidée de Diligences (ex-Suivi Juridique), captures dans assets/img/diligences/
- assets/fonts/ ......... polices Zilla Slab, Archivo, IBM Plex Mono (hébergées avec le site)
- assets/img/ ........... favicon et image de partage (og-image.jpg)
- assets/media/ ......... vidéo de présentation (presentation.mp4) et son affiche (poster.jpg)

1) Ajouter les liens de téléchargement
   Ouvre index.html, cherche « LIENS DE TÉLÉCHARGEMENT » (en bas du fichier) et remplis :
     mac:     "…/Paraphe_1.0.0_universal.dmg"
     windows: "…/Paraphe_1.0.0_x64-setup.exe"
   Tant qu’un lien est vide, le bouton affiche « Bientôt disponible ».
   Tu peux soit déposer les fichiers dans un dossier du site (ex. telechargements/),
   soit mettre une adresse complète (GitHub Releases, Google Drive partagé en « Tous les utilisateurs disposant du lien »…).

2) Image de partage (réseaux sociaux)
   Une fois le site en ligne, remplace dans index.html
     <meta property="og:image" content="assets/img/og-image.jpg">
   par l’adresse complète, ex. https://ton-site.fr/assets/img/og-image.jpg

3) Mettre en ligne
   Dépose tout le dossier tel quel (index.html à la racine) sur GitHub Pages, Netlify, OVH, etc.
   Aucune dépendance externe : tout fonctionne hors ligne.

4) Bon à savoir
   - Les démos de la page (cartes, fiche d’arrêt, pipeline, arbre, frise…) sont des
     reproductions simplifiées : rien n’est enregistré, un rechargement remet tout à zéro.
   - Le rideau d’ouverture ne s’affiche qu’une fois par session de navigation.
   - Si le visiteur a activé « réduire les animations » dans son système, les effets
     sont coupés automatiquement.

5) Pages légales (mentions-legales.html)
   Avant la mise en ligne, compléter les passages surlignés en jaune « [à compléter] » :
   - ton adresse e-mail de contact (2 endroits) ;
   - l’hébergeur : nom, adresse, téléphone ou site. Exemples :
       GitHub Pages : GitHub Inc., 88 Colin P. Kelly Jr Street, San Francisco, CA 94107, États-Unis — github.com
       Netlify : Netlify Inc., 101 2nd Street, San Francisco, CA 94105, États-Unis — netlify.com
       OVHcloud : OVH SAS, 2 rue Kellermann, 59100 Roubaix, France — 1007 (depuis la France)
     (vérifie l’adresse à jour sur le site de ton hébergeur)
   - Option « anonymat » : si tu préfères publier ton adresse et ton téléphone plutôt que de
     t’appuyer sur l’hébergeur, ajoute-les dans « Éditeur » et supprime l’encadré violet.
   Les licences des polices sont dans assets/fonts/LICENCES.txt (obligatoire avec les polices).

6) En ligne
   Adresse du site : https://parpar30.github.io/Paraphe-Site/
   Dépôt GitHub    : https://github.com/PARPAR30/Paraphe-Site (branche main, GitHub Pages)
   Pour mettre à jour : modifie les fichiers ici, puis « git push » depuis ce dossier (ou
   « Add file → Upload files » sur github.com/PARPAR30/Paraphe-Site). Le site se met à jour en ~1 minute.

7) Installateurs (logiciels/)
   - Paraphe_1.0.0_universal.dmg (macOS, Intel + Apple Silicon) et
     Paraphe_1.0.0_x64-setup.exe (Windows 64 bits), compilés depuis le dossier Code.
   - Ils ne sont pas signés par un certificat d'éditeur : à la première ouverture, macOS
     (clic droit → Ouvrir) et Windows (SmartScreen → Informations complémentaires → Exécuter
     quand même) affichent un avertissement.
   - Les données des utilisateurs sont reprises automatiquement au premier lancement
     (l'ancien dossier de données n'est pas modifié).

8) Vidéo de présentation (assets/media/presentation.mp4, 2 min, avec son)
   Refaite le 2 octobre 2026 : les six outils utilisés pour de vrai dans l'application, étape par étape
   (légendes numérotées, élément mis en évidence, caméra qui suit l'action). Affiche : poster.jpg.
   Musique et bruitages originaux, générés par programme : un menuet écrit sur les notes du mot
   PARAPHE (si, la, ré, la, si, la, mi). Aucun morceau ni échantillon tiers, pas de droits à déclarer.
   Sources et marche à suivre pour la refaire : Code/docs/video/.
